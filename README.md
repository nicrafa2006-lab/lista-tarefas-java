# Lista de Tarefas (Java)

Projeto simples de console para praticar Java: adicionar, listar, concluir e remover tarefas.

## Estrutura

- `Main.java` — menu e lógica do programa
- `Tarefa.java` — classe que representa uma tarefa

## Como executar

Requer JDK 17 ou superior.

```bash
javac Main.java Tarefa.java
java Main
```
